About This Testbed

Hurricane Testbed lets you launch simulated tropical cyclones at any point on Earth using real-world-style presets, and explore a catalog of major historical hurricanes, typhoons, and cyclones.

Loading screen uses the BobloxClassic font (same as ArmorTest). The rest of the interface stays clean and professional.

Custom domain: hurricanetest.org (CNAME configured for GitHub Pages).

Educational / research exploration tool. Not an official NOAA product.
